001 / Build

vsmlite

Help one organization learn to stand on its own.

vsmlite starts with one parent organization and one child. The parent provides the support the child still needs: coordination, oversight, planning, and rules.

As the child proves it can handle more, the parent hands over responsibility. Each step has visible evidence and can be reversed if needed.

Start with one working relationship

Before building a whole network of organizations, we test the smallest useful case. One parent. One child. A clear record of what changed and why.

Independent, with clear boundaries

A child is autonomous when it can carry out its mission and manage its own work within agreed rules. It still stays connected to its parent.
