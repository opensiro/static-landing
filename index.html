01 / The idea

From structure to evidence

A clear structure.
A system that runs.
Results you can inspect.

An organization needs a purpose, roles, and rules for making decisions. We want those things to be clear enough to describe in code and run as a working system.

Our work connects two questions: how do we build systems that can work on their own, and how do we know they work? vsmlite explores the first. The opensiro platform and ARCTIC explore the second.

  1. [01]

    Describe

    Set the mission, responsibilities, and boundaries of an organization.

  2. [02]

    Build

    Turn that structure into a system. Start small and give it more responsibility as it proves itself.

  3. [03]

    Test

    Measure its work on shared tasks. Inspect the results and learn from failures.
