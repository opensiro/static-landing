Promotion criteria

Prefer general mechanisms.
Reject model-specific luck.

  1. 01Positive effect on most heterogeneous SLMs.
  2. 02No single model or family determines the result.
  3. 03The gain persists across several task types.
  4. 04More tokens, tools or steps do not explain the gain.
  5. 05No major regression on a model or task class.
  6. 06Incremental cost is proportional to expected value.
  7. 07The mechanism still makes sense as model capability grows.

When to use the sandbox

Reserve the matrix
for uncertain, expensive changes.

Run Cross-SLM
  • new tools and representations
  • planners and verifiers
  • memory and state mechanisms
  • parallel or multi-agent execution
  • new execution policies
  • major context strategies
  • experimental environment interaction
Stay at L0 / L1
  • ordinary bug fixes
  • small prompt changes
  • local implementation changes
  • deterministic regressions

Cross-model evidence is useful only when uncertainty and downstream frontier cost justify it.

OpenSiro claim

?

Whether gains consistent across heterogeneous SLMs select frontier-positive capabilities efficiently.

What the CMU study supports: adapted small models can approach a large-model baseline at a small fraction of cost across seven business tasks and three SLM families.

What it does not establish: that cross-SLM agreement predicts frontier harness improvement. OpenSiro must measure that transfer precision, recall, avoided frontier runs and failure distribution.

Source: Better Harnesses, Smaller Models ↗. Promotion means “worth a more expensive experiment,” not “frontier improvement proven.”
